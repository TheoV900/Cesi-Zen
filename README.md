# CESIZen 

Application web de gestion du stress et de la santé mentale.  
Projet réalisé dans le cadre du Bloc 3 : Déployer et sécuriser les applications informatiques (CDA).

---

##  Technologies utilisées
- **Backend** : [NestJS](https://nestjs.com/) + [Prisma](https://www.prisma.io/) + PostgreSQL
- **Frontend** : [Next.js](https://nextjs.org/) + React + Tailwind CSS + SWR
- **Base de données** : PostgreSQL (via Docker)
- **Outils** : GitHub, Docker, GitHub Actions

---
